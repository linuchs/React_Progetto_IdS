Creazione di un Single-Page Applicazion per la visualizzazione e la ricerca di dati provenienti da un file CSV.
 https://ingegneriadelsoftware.firebaseapp.com/
        <p className="mb-0" >
        L'interfaccia permette di caricare un il file che verrà visualizzato su una tabella. 
        Dall'interfaccia premendo su "Sfoglia" comparirà la finesta dalla quale l'utente potrà scegliere il file desiderato, 
        successivamente verrà visualizzato il nome del file scelto e e il pulsante "Carica File",
        premendo il quale verrà visualizzato il file csv in una tabella.
      </p><p className="mb-0">
        Si può effettuare una ricerca per riga: indipendentemente dalle colonne selezionate verranno
        visualizzate le sole righe dove compare la chiave cercata.
        Inoltre l'interfaccia permette di effettuare una ricerca sulle colonne del file,</p>
        <p className="mb-0">è possibile affinare la ricerca su più colonne utilizando più chiavi di ricerca.
      </p>
      <p className="mb-0">
       Attaverso il menù a tendina "Seleziona altre colonne della tabella", si possono visualizzare tutte le colonne,
       oppure scegliere singole colonne.
        </p>
      <p className="mb-0">
       Una volta effettuata la ricerca si può esportare il risultato filtrato su un file CSV,
       verranno esportate esclusivamente le colonne selezionate e le righe visualizzate sullo schermo, le pagine possono essere 
       sfogliate attaverso gli appositi strumenti in fondo alla tabella.
          </p>
      <p className="mb-0">Sono stati utilizzati i seguenti strumenti: la libreria <b>React di Javascript</b> e <b>Bootstrap per React</b>,
        per la visualizzazione e la ricerca sulla tabella è stato utilizzato il componente <b>react-bootstrap-table2.</b>
        </br>Il link relativo al file CSV:</p>
      
      https://data.bioontology.org/ontologies/OBIB/download?apikey=8b5b7825-538d-40e0-9e9e-5ab9274a9aeb&download_format=csv
